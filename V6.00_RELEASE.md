# JejakNasab V6.00

V6.00 is a structural release based on V5.21. It keeps the existing D1 data model compatible while introducing a separate **Cabang Keluarga** context.

## Main changes

- Silsilah Opsional is renamed in the UI to **Cabang Keluarga**.
- Main-tree members and branch-only members are separated by context.
- Branch-only people use `persons.main_visible=0` and do not appear in the main tree.
- A branch can link an existing main-tree person instead of duplicating that person.
- Creating a branch automatically includes the anchor's existing spouse, children, and parents when those relationships already exist in the main tree.
- Branch limits are enforced server-side: 2 generations up and 2 generations down.
- Sibling side-paths can include spouse and descendants up to 2 generations down; upward traversal through a sibling/spouse path is rejected.
- Premium Family Member limit: 5, with 3 generations up and 2 down.
- Ultimate Family Member limit: 20, with 6 generations up and 6 down.
- Main-tree side access includes siblings, spouses, and 2 generations of side descendants.
- Password confirmation and show/hide password controls are added to registration and login.
- Front and rear titles are stored and rendered in trees and public profiles.
- Child ordering remains separately configurable for the main tree and branch context.
- Owner-only audit history remains restricted to the Owner Account.
- Public branch links are available when the main tree is public.
- Registration now explicitly states that V6.00 is waiting for Owner Web approval; payment automation is intentionally not enabled yet.
- Existing V5 optional-lineage records are migrated into branch tables on first V6 initialization.

## Database migration

For an existing production D1 database, run `migration-v6.sql` once. Do not reset or delete the existing D1 database.

For a new database, use `schema.sql`.
