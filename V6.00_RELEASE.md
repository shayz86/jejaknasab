# JejakNasab v6.00 Release

## Baseline

v6.00 dibangun dari ZIP JejakNasab v5.21 yang diberikan pengguna. Tidak menggunakan aplikasi baru dari nol.

## Fokus rilis

1. Pemisahan konteks Pohon Utama dan Cabang Keluarga.
2. Pembatasan generasi Premium/Ultimate yang asimetris (Premium 3 atas/2 bawah).
3. Cabang 2 atas/2 bawah + jalur saudara/pasangan/keturunan maksimal 2.
4. Search di dropdown anggota utama.
5. Gelar depan/belakang.
6. Konfirmasi password + icon mata.
7. Dashboard Family Member/Owner menggunakan graph yang konsisten.
8. Urutan anak cabang terpisah dari urutan anak utama.
9. Riwayat audit tetap hanya Owner Akun.
10. Status pendaftaran/payment tetap kompatibel dengan alur verifikasi Owner Web.

## Migrasi D1

Jangan menghapus database lama. Jalankan `migration-v6.sql` untuk tabel/index baru jika diperlukan. API v6 juga melakukan upgrade kolom secara idempotent saat menerima request.
