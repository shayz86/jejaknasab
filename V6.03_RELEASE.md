# JejakNasab V6.03

## Perbaikan deployment
- Memperbaiki syntax error JavaScript pada `functions/api/[[path]].js` yang menyebabkan Cloudflare Pages gagal membangun Functions.
- Query SQL `/trees` untuk Owner Akun sekarang menggunakan template literal JavaScript sehingga tanda kutip SQL `premium` tidak memutus string JavaScript.
- Semua file JavaScript telah diperiksa dengan `node --check` dan lolos syntax check.

## Fitur V6.02 yang dipertahankan
- Link publik stabil.
- Family Member menggunakan paket Owner Akun.
- Scope Family Member mempertahankan pasangan yang relevan.
- Tombol zoom aktif.
- Tombol Cabang Keluarga terhubung ke API CRUD.
- Halaman undangan `/invite?token=...` tersedia.
- Health endpoint menampilkan versi V6.03.

## Deployment
1. Push isi project ke branch yang dipakai Cloudflare Pages.
2. Tunggu build selesai.
3. Tes `https://jejaknasab.pages.dev/api/health`.
4. Setelah health berhasil, tes link `/f/[token]`.

Jangan menjalankan `schema.sql` terhadap database production.
