# JejakNasab V5.20

## Fokus
Perbaikan tampilan dan konsistensi pohon pada Owner/Family Member/public serta perapian picker anggota dan daftar silsilah opsional.

## Perubahan
1. Search anggota sekarang berada di dalam dropdown `Hubungkan ke anggota yang sudah ada`.
2. Dashboard hanya menampilkan anggota utama yang reachable dari root dan memiliki silsilah opsional.
3. Root tree dipakai secara konsisten ketika membuka dashboard.
4. Connector suami-istri dibuat sebagai elemen tersendiri sehingga garis selalu berada di ruang antara kotak.
5. `public.js` disamakan dengan script utama.

Migration database tidak diperlukan untuk v5.20.
