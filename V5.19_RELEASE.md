# JejakNasab V5.19

- Dashboard no longer renders large optional lineage trees inline. It shows a compact **Silsilah Opsional** list; each member opens the optional tree in a modal.
- Added optional child ordering, persisted in `optional_lineages.sibling_order`.
- Added search/filter input for **Hubungkan ke anggota yang sudah ada**.
- Fixed spouse connector spacing so husband/wife cards have a visible gap with the relationship line centered between them.
- Main lineage remains separate from optional lineage.

## Database

Run `migration-v5.19.sql` once against the existing D1 database. The API also attempts to add the column automatically on request for environments where migrations are not run manually.
