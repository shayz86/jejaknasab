# JejakNasab V5.17 Release

## Tujuan
V5.17 memperbaiki fondasi pohon agar konsisten dengan konsep nasab garis ayah dan menambahkan dukungan multi-istri serta riwayat pasangan.

## Perubahan
1. `family_trees.root_person_id` menjadi root utama yang konsisten.
2. Root otomatis diprioritaskan laki-laki dan garis ayah.
3. Renderer dashboard Owner, Family Member, Owner Web, dan publik memakai root yang sama.
4. Garis pasangan berada di antara node pasangan.
5. Garis turun dari tengah pasangan menuju garis horizontal anak dan konektor masing-masing anak.
6. Satu suami dapat memiliki beberapa istri.
7. Satu istri hanya memiliki satu suami aktif.
8. Hubungan pasangan memiliki status aktif/berakhir serta tanggal mulai/berakhir.
9. Suami yang tercatat wafat memungkinkan hubungan lama diakhiri otomatis ketika istri dicatat mempunyai suami berikutnya.
10. Owner Akun memiliki menu `Pasangan & Riwayat` untuk mengakhiri hubungan dan menyimpan riwayat.

## Deploy ke Cloudflare
### Database produksi yang sudah ada
Jalankan sekali:

```bash
npx wrangler d1 execute jejaknasab-db --remote --file=migration-v5.17.sql
```

Jangan reset database dan jangan menjalankan `DROP`.

### Pages
Upload/push seluruh isi project. `wrangler.toml` tetap menggunakan binding `DB` dan output `public`.

## Catatan
V5.17 tidak menghapus data V5.16. Relasi pasangan lama dianggap aktif sampai diberi status/tanggal berakhir.
