# JejakNasab V6.02

## Perbaikan
- Link publik stabil: membuka dashboard tidak lagi mengganti token publik.
- API `/trees/:id/share` mengembalikan paket Owner Akun, sehingga Family Member melihat paket yang benar.
- Scope Family Member menyertakan pasangan dari leluhur yang terlihat agar pasangan teratas tidak hilang.
- Tombol zoom pohon utama, publik, dan cabang kini aktif.
- Tombol **Cabang Keluarga** kini membuka manager dan terhubung ke API CRUD cabang.
- Menambahkan halaman undangan `/invite?token=...` yang sebelumnya belum memiliki handler di frontend.
- Health endpoint menjadi V6.02.
- Migrasi V6 SQL dibuat idempotent; perubahan kolom tetap ditangani runtime oleh `ensureExtras()`.

## Catatan deployment
